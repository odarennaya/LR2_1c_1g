   Создать понятную структуру папок, использовать README и вести небольшую историю изменений.
# 2. Состав файлов
   Ноутбук первой лабораторный находится в файле Notebooks/ЛР1_ФиПЛ_1к_1гр_Гришина.ipynb

   Загрузить ноутбук в папке notebooks.
   Открыть файл .ipynb в Google Colab.
   Проверить наличие файлов из папки data.
# 4. Проверка
 1  открыть notebook;
 2  выполнить Restart runtime → Run all;
 3  проверить, что ячейки выполняются без ошибок;
# 5. Ограничения 
  Перед запуском кода нужно проверить наличие всех файлов и правильность их расположения.
